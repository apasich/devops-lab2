# DevOps Lab 2

## Cel
Ćwiczenie podstaw Git i GitHub: commity, gałęzie, Pull Request, code review.

## Wykorzystane narzędzia
- Git
- GitHub
- Terminal

## Instrukcja pracy
1. Utworzenie repozytorium `devops-lab2` na GitHubie i sklonowanie go lokalnie.
2. Utworzenie gałęzi `feature/update-readme`.
3. Uzupełnienie README.md i zapisanie zmian w commicie.
4. Wypchnięcie gałęzi na GitHuba (`git push`).
5. Utworzenie Pull Requesta, code review i merge do `main`.
